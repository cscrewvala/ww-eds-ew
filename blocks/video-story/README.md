# video-story

Custom **video** block. Purpose: story-video.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, one cell of content.

## Supported variations

- `tile`: bordered content-tile card with a 1190:575 poster cropped from the top (source
  `.cmp-teaser--tile-video`). Applied automatically when the block has a caption and links a direct
  video file (.mp4 etc.); can also be authored as `Video Story (tile)`.
