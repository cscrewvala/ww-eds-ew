# columns-media

Custom **columns** block. Purpose: explanatory-text-with-photo.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, one cell of content.

## Supported variations

- `image-border`: photo in a 16px white frame with 32px corners (source `.image.with-border`, e.g. privacy/usage).
- `bullets-berry`: list items with 10px berry dots instead of discs (source `.text.custom-bullets--berry`, e.g. privacy/usage).
