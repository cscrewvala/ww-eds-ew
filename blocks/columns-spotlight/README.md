# columns-spotlight

Custom **columns** block. Purpose: featured-media-spotlight.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, one cell of content.

## Supported variations

- `dual`: text left, full-bleed poster right (source `imagevideotext.dual-container`). Applied
  automatically on `legal-page` template pages; can also be authored as `Columns Spotlight (dual)`.
