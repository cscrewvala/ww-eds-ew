# cards-stats

Custom **cards** block. Purpose: key-figures-and-goals.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, one cell of content.

## Supported variations

- `panel`: rounded container. First row (optional) = heading + intro
  paragraph(s); last row (optional) = a single CTA link, rendered as a centred
  outlined button with a chevron. Add `tint-sky-5` (`cards-stats (panel, tint-sky-5)`)
  for the tinted background.
