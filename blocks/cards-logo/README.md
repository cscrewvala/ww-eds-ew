# cards-logo

Custom **cards** block. Purpose: brand-ecosystem-cards.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, one cell of content.

Row: logo | name (heading), optional description paragraph(s)/list, optional link.
The description (a "Read more" pop-up on the source) is shown inline, clamped to
2 lines, with a "Show more" / "Show less" toggle that only appears when it overflows.

## Supported variations

No variations.
