# quote-story

Custom **quote** block. Purpose: pull-quote.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, one cell of content.

## Supported variations

- *(default)* — pull quote: blue opening/closing quote marks, attribution eyebrow above, large heading-font quote text (source `.pullquote`).
- `blockquote` — inline rich-text blockquote: no quote marks, body-font italic text, attribution below prefixed with "- " (source `.cmp-text blockquote`, e.g. refrigeration-apprenticeship-program).
